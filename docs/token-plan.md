# LLM Token 使用计划（AICR 模板）

## 1. 申请目标

- 支撑企业内部知识问答、流程自动化和策略审查
- 通过 AICR 架构保证高可用、可追溯、可控成本

## 2. 技术架构

- RAG：基于企业文档检索后再生成，降低幻觉
- 知识图谱：补充实体关系推理，增强可解释性
- Agent：执行多步骤任务（检索、判断、调用工具、输出）
- MCP：接入审批系统、策略服务、日志服务等外部能力
- Skill：沉淀可复用能力（预算估算、风险检查、合规审阅）

## 3. Token 预算（初版）

- 日均预算：150k token
- 峰值预算：500k token
- 月度上限：6M token

## 4. 成本优化策略

- Query 重写与缓存，减少无效检索
- 分层模型策略：简单问答走轻量模型，复杂任务走高能力模型
- 上下文裁剪与摘要，控制输入长度
- 对高频请求做 Skill 化，避免重复推理

## 5. 风险与治理

- 幻觉风险：RAG + 图谱双重校验
- 数据风险：MCP 访问策略与审计日志
- 成本风险：实时 token 监控与超限熔断

## 6. 交付物
